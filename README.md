# sergipa.github.io

The developer website for **Spotimals**, a hidden-object game for iOS and Android. Served by GitHub Pages at https://sergipa.github.io/.

| Page | What it is for |
| --- | --- |
| [`/`](https://sergipa.github.io/) | Landing page: developer website and support URL in the App Store and Google Play listings. |
| [`/spotimals/privacy.html`](https://sergipa.github.io/spotimals/privacy.html) | Privacy policy, linked from both store listings and the AdMob consent message. |
| [`/app-ads.txt`](https://sergipa.github.io/app-ads.txt) | AdMob authorised sellers file; it has to be at the root of the domain. |

Plain HTML, no build step. Edit a file, push to `main`, and Pages republishes within a minute or two.

The game's source and the launch checklist live in the [FindAnimals](https://github.com/sergipa/FindAnimals) repository (`docs/website/` there is the copy of this site kept next to the code).
