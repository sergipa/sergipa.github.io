Spotimals

Find the animals in the crowd.

What it is

A hidden-object game for phones. Each level asks for a few animals ("5 Brown Rabbits", "Bears with hats") hiding in a crowd that wanders around a big map: a farm, a city, a theme park, a mall. Time limits, costume changes and dressed-up decoys keep it tricky.

Privacy
